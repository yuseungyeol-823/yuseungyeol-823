# yuseungyeol

**Backend · IoT · Machine Learning**

Java와 Spring으로 API를 만들고, 데이터를 서비스로 연결합니다.  
실시간 IoT 대시보드부터 머신러닝 모델 실험까지, 직접 구현하며 배우고 기록합니다.

### Stack

- **Backend** — Java · Spring Boot · Spring Data JPA · MySQL
- **Web & IoT** — TypeScript · React · SSE · Raspberry Pi
- **ML** — Python · LightGBM · CatBoost · PyTorch
